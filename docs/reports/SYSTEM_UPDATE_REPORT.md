### 2. 📈 Система скейлинга по требованиям

Каждый предмет имеет параметр `requirements` (словарь требуемых статов).

**Расчет эффективного бонуса:**
```
Если статое >= требование:
  Доп. бонус = (статка - требование) × 0.02 для оружия
  Доп. бонус = (статка - требование) × 0.03 для брони
```

**Примеры:**
- Воин (атака 15) + Боевой топор (требует 10): +16 → 18 дмг (+12%)
- Маг (интеллект 12) + Мистическая роба (требует 12): +27 → 27 защ (0% штраф)
- Разбойник (ловкость 10) + Стальной лук (требует 7): +40 → 44 дмг (+10%)

### 3. 🛡️ Система УКЛОНЕНИЯ (DODGE)

**Определение:** Вероятность избежать урон

**Формула:**
```
evade_chance = ловкость × 0.5% (максимум 50%)
```

**Механика:**
- Проверяется при получении урона
- При успехе урон = 0
- Враги также имеют шанс уклонения

**Примеры:**
- Ловкость 0 → 0% эвейда
- Ловкость 10 → 5% эвейда
- Ловкость 20 → 10% эвейда
- Ловкость 40 → 20% эвейда (максимум 50% при ловкости 100)

### 4. ⚡ Система КРИТИЧЕСКИХ УДАРОВ (CRIT)

**Определение:** Шанс нанести 150% урона вместо 100%

**Формула:**
```
crit_chance = ловкость ÷ 300% или 1/3 процента за ловкость (максимум 40%)
```

**Механика:**
- Проверяется при атаке (игрока и врага)
- Урон умножается на 1.5 при крите
- Оба участника боя могут наносить крит

**Примеры:**
- Ловкость 0 → 0% крита
- Ловкость 9 → 3% крита
- Ловкость 15 → 5% крита
- Ловкость 30 → 10% крита

### 5. 🎮 Интеграция в боевую систему

#### Логика атаки игрока:
1. Враг пытается уклониться → возвращаемся к атаке врага
2. Поверяется критический удар
3. Если крит → урон × 1.5
4. Применяются артефакты (lifesteal, etc.)

#### Логика атаки врага:
1. Игрок пытается уклониться (сообщение в консоль)
2. Враг пытается нанести крит
3. Если крит → урон × 1.5
4. Применяется элементальный урон/сопротивления
