## ⚡ СИСТЕМЫ БОЕВОГО БАЛКНОСА

### 1. УКЛОНЕНИЕ (DODGE)

**Как работает:**
- Зависит от ЛОВКОСТИ
- Шанс уклонения = ловкость × 0.5% (макс 50%)
- При срабатывании урон полностью избежан

**Для игрока Разбойника с ловкостью 20:**
```
Шанс уклонения = 20 × 0.5% = 10%
```

### 2. КРИТИЧЕСКИЕ УДАРЫ (CRIT)

**Как работает:**
- Зависит от УДАЧИ (LUCK)
- Шанс крита = ловкость ÷ 300% (макс 40%)
- Критический удар наносит 150% урона

**Для врага с ловкостью 9:**
```
Шанс крита = 9 ÷ 3 = 3%
При крите: урон × 1.5
```

## 🎯 ПРАКТИЧЕСКИЕ ПРИМЕРЫ

### Пример 1: Боец vs Гоблин

```
БОЕЦ (16 уровень):
- Атака: 18
- Защита: 8
- Ловкость: 2
- Экипировка: Боевой топор + Пластинчатая броня

Расчет УКЛОНЕНИЯ: 2 × 0.5% = 1% (почти нет)
Расчет КРИТА: 2 ÷ 3 = 0.67% (практически нет)

Урон боевого топора: 15 + 8 (бонус качества) = 23 урона за удар
При крите: 23 × 1.5 = 35 урона

ГОБЛИН:
- Уклонение: ~0% (враг 1 уровня)
- Крит: ~0%
- Урон: 8-10 (базовый)

ИСХОД: Боец одолеет без проблем
```

### Пример 2: Маг vs Огр

```
МАГ (15 уровень):
- Атака: 18
- Защита: 4
- Интеллект: 14
- Ловкость: 8
- Экипировка: Древний посох + Зачарованная роба

Расчет УКЛОНЕНИЯ: 8 × 0.5% = 4%
Расчет КРИТА: 8 ÷ 3 = 2.67% (~2.7%)

Урон древнего посоха: 28 + 10 (бонус) = 38 урона за удар
При крите: 38 × 1.5 = 57 урона

ЗАЩИТА: 4 + 16 = 20 защиты (слабо против Огра)

ТАКТИКА: Маг должен полагаться на уклонение и крит
```

### Пример 3: Разбойник vs Скелет

```
РАЗБОЙНИК (14 уровень):
- Атака: 14  
- Защита: 8
- Ловкость: 12
- Экипировка: Стальной лук + Теневая кожа

Расчет УКЛОНЕНИЯ: 12 × 0.5% = 6% (хорошее уклонение)
Расчет КРИТА: 12 ÷ 3 = 4% (заметный крит)

Урон стального лука: 22 + 12 (бонус) = 34 урона за удар
При крите: 34 × 1.5 = 51 урона

ЗАЩИТА: 8 + 14 = 22 защиты (достаточно)

ПРЕИМУЩЕСТВО: Ловкость дает 6% уклонения и 4% крита
Разбойник может избежать большей части урона
```

## 🎮 КАК ИГРАТЬ

### Воин (Warrior)
```
1. Ищите мечи, топоры, тяжелую броню
2. Требования: Атака 10-15
3. Стратегия: Высокий урон + защита

### Маг (Mage)
```
1. Ищите посохи и роба
2. Требования: Интеллект 10-14
3. Стратегия: Управляемый урон + уклонение
4. Левел-ап: Интеллект → Защита → Удача

```
1. Ищите луки и кожаную броню
2. Требования: Ловкость 7-10
3. Стратегия: Уклонения + крит-урон
4. Левел-ап: Ловкость → Удача → Атака
```
