# 🔧 Админ режим

## Описание

Админ режим предоставляет полный контроль над игровым процессом для тестирования и отладки.

## Как активировать

1. Открыть меню **"🎨 Тема"**
2. Внизу окна найти секцию **"Админ режим"**
3. Нажать кнопку **"⚙️ Переключить"**
4. Ввести пароль: `admin123`
5. После успешного входа в главном меню появится кнопка **"⚙️ Админ"**

## Возможности админ режима

### 📊 Характеристики
Быстрое добавление характеристик игроку:
- Атака (+1, +10)
- Защита (+1, +10)
- Макс. HP (+10, +100)
- Огнестойкость (+5, +50)
- Холодостойкость (+5, +50)
- Удача (+1, +10)
- Интеллект (+1, +10)

### 📖 События
- Просмотр полного списка всех событий
- Ручной вызов любого события
- Информация о локации и сложности события
- Обход обычной механики случайных встреч

### ⚔️ Бой
Призыв врагов с настройкой параметров:
- Выбор уровня врага (1-100)
- Выбор ротации врага (0-50)
- Мгновенное начало боя без исследования

### 🎮 Игрок
Прямое редактирование параметров игрока:
- **HP**: Восстановление полного HP или установка точного значения
- **Опыт**: Добавление опыта (+100, +1000)
- **Уровень**: Установка любого уровня (1-100)
- **Золото**: Добавление золота (+100, +1000, +10000)
- **Ротация**: Изменение ротации (-1, +1, установить точное значение)

## Безопасность

- Пароль по умолчанию: `admin123`
- Пароль можно изменить в файле `gui_main.py` (переменная `self.admin_password`)
- Админ режим не влияет на основной игровой процесс
- Можно в любой момент выключить через то же меню тем

## Отключение админ режима

1. Открыть меню **"🎨 Тема"**
2. Нажать кнопку **"⚙️ Переключить"**
3. Режим будет выключен, кнопка "⚙️ Админ" исчезнет из меню

## Примечания

- Все изменения через админ панель сохраняются в текущей игре
- Рекомендуется использовать для тестирования баланса и событий
- При использовании админ режима игра остаётся полностью функциональной
