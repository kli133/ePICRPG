# ⚔️ ePICRPG

**Текстовая RPG с графическим интерфейсом на Python и Tkinter**

Классы и навыки, пошаговые бои, генерация снаряжения по качеству,
артефакты со случайными бонусами, события с выбором, престиж и ротации.

## 🚀 Быстрый старт

### Готовая сборка (Windows)

Скачайте `ePICRPG.exe` из раздела [Releases](../../releases) и запустите. Python не нужен.

### Из исходников

Нужен Python 3.8+ с Tkinter (входит в стандартную установку на Windows и macOS).

```bash
git clone https://github.com/kli133/ePICRPG.git
cd ePICRPG
python gui_main.py
```

> На Linux Tkinter может понадобиться установить отдельно: `sudo apt install python3-tk`.

Сторонние зависимости для самой игры не нужны. `requirements.txt` содержит только PyInstaller для сборки EXE.

## 🎮 Игровые механики

<details>
<summary><b>🧙 Классы персонажей</b></summary>

| Класс | Бонусы | Способность | Перезарядка |
|---|---|---|---|
| ⚔️ **Воин** | +30 HP, +5 атака, +3 защита, +5 к сопротивлениям | **Удар ярости**: частично игнорирует защиту врага | 3 хода |
| 🔮 **Маг** | +10 HP, +8 атака, −1 защита, +2 интеллект | **Молния**: сильный урон и оглушение на 1 ход | 4 хода |
| 🗡️ **Разбойник** | +15 HP, +4 атака, +3 защита | **Уклонение**: избегает следующей атаки | 3 хода |
| 🍀 **Удачливый** | +5 удача | Повышенный шанс лута и золота | — |

Навыки прокачиваются до 5 уровня, сила растёт от связанной характеристики (атака или интеллект).
</details>

<details>
<summary><b>⚔️ Боевая система</b></summary>

- **Крит** — 150% урона, шанс зависит от удачи
- **Уклонение** — урон полностью избегается, шанс зависит от ловкости (до 50%)
- **Стихийный урон** — огонь и холод, снижается сопротивлениями
- **Навыки врагов** — огненное дыхание, удар щитом, похищение жизни
- **Звери** (волки, крысы и т. д.) не используют магию

Враги 5 тиров: от гоблинов и крыс до древних драконов и Повелителя тьмы. Их сила растёт с ротацией.
</details>

<details>
<summary><b>🛡️ Снаряжение и качество</b></summary>

Качество предметов по возрастанию:

`▢ Деревянное` → `Ржавое` → `Железное` → `Серебряное` → `Роскошное` → `🐉 Драконье`

Каждый предмет требует определённую характеристику: силу для воина, интеллект для мага, ловкость для разбойника.
За каждый пункт сверх требования оружие получает +2% к бонусу, броня +3%.

Подробнее: [docs/EQUIPMENT_BALANCE.md](docs/EQUIPMENT_BALANCE.md)
</details>

<details>
<summary><b>💎 Артефакты</b></summary>

Артефакт генерируется с 1–5 слотами. Слотов тем больше, чем выше ротация и удача игрока. Возможные бонусы:

- Характеристики: атака, защита, HP, интеллект, удача, сопротивления огню и холоду
- Боевые: +% к шансу крита, +% к уклонению

Подробнее: [docs/ARTIFACT_SLOTS_SYSTEM.md](docs/ARTIFACT_SLOTS_SYSTEM.md)
</details>

<details>
<summary><b>🔁 Престиж и ротации</b></summary>

**Престиж** открывается на 50 уровне (каждый следующий на 15 уровней позже). Персонаж сбрасывается, но навсегда получает за каждый уровень престижа:

| Бонус | За уровень |
|---|---|
| ❤️ HP | +20 |
| ⚔️ Атака | +3 |
| 🛡️ Защита | +2 |
| 📊 Очки характеристик | +2 |
| ✨ Опыт | +5% |
| 💰 Золото | +7% |
| 🎁 Шанс лута | +2% |

**Ротация** усиливает врагов и одновременно повышает награды, качество лута и ассортимент магазина.
</details>

<details>
<summary><b>📜 События</b></summary>

Во время исследования могут случиться события: встреча с драконом, торговцем или бандитами, загадка волшебника, пещера с сокровищами и другие.
У каждого выбора есть проверки (характеристика, удача или их комбинация) и разные исходы.

Как добавить своё событие: [docs/EVENTS_GUIDE.md](docs/EVENTS_GUIDE.md)
</details>

## 📦 Сборка EXE

```bash
pip install -r requirements.txt
python build_exe.py
```

Готовый файл появится в `dist/ePICRPG.exe`. Если в `PATH` или в переменной `UPX_DIR` есть [UPX](https://github.com/upx/upx/releases), он будет использован для сжатия.

Подробнее: [docs/BUILD_EXE.md](docs/BUILD_EXE.md)

## 🗂️ Структура проекта

```
ePICRPG/
├── gui_main.py        # Графический интерфейс, точка входа
├── launcher.py        # Точка входа для EXE-сборки
├── player.py          # Игрок: характеристики, уровни, престиж, навыки
├── classes.py         # Классы персонажей и их способности
├── skills.py          # Описание навыков и их скейлинга
├── combat.py          # Враги и боевая логика
├── items.py           # Предметы, качество, генерация снаряжения и артефактов
├── inventory.py       # Инвентарь, продажа, улучшение предметов
├── events.py          # Движок событий
├── events_data.py     # Набор игровых событий
├── save_system.py     # Сохранения (5 слотов) и настройки
├── locales.py         # Локализация RU / EN
├── ui.py              # Вспомогательные функции интерфейса
├── version.py         # Название и версия игры
├── build_exe.py       # Скрипт сборки EXE
├── ePICRPG.spec       # Конфигурация PyInstaller
├── tests/             # Тестовые сценарии
└── docs/              # Документация
```

## 🧪 Тесты

Тесты оформлены как скрипты. Их запускают из корня проекта:

```bash
python -m tests.test_upgrade
python -m tests.test_artifact_slots
python -m tests.test_scaling_system
```

> На Windows при ошибке `UnicodeEncodeError` установите `PYTHONIOENCODING=utf-8`.
